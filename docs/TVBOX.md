# TVBox / OrionTV 订阅接入指南

KatelyaTV 提供标准的 TVBox 订阅接口：把站内配置好的全部采集源打包成一份订阅，
TVBox、OrionTV 等客户端导入后即可直接搜索、播放，无需在客户端逐个配置源。

> 本文档描述的是当前代码的真实行为（1.3.0）。早期版本文档中的
> `?format=base64` 参数、「配置缓存 1 小时」、「推荐使用站内解析接口」等说明均已过时。

## 1. 获取订阅链接

1. 登录 KatelyaTV，打开侧边栏「TVBox 配置」（页面地址 `/config`）；
2. 选择格式：
   - **JSON 格式**（默认，推荐）：`/api/tvbox?token=<令牌>&format=json`
   - **Base64 格式**：`/api/tvbox?token=<令牌>&format=txt`
3. 点击「复制」。

> 格式参数只有 `json` 与 `txt` 两个合法值；传其它值（例如 `format=base64`）会静默回退为 JSON。
> 订阅链接内含访问令牌，等同于一把钥匙，请只给信任的设备 / 家人使用。

## 2. 令牌与安全

令牌的两种校验位置任选其一：

- 查询参数：`?token=<令牌>`
- 请求头：`x-tvbox-token: <令牌>`

令牌值有两种来源：

| 来源 | 条件 | 特点 |
|---|---|---|
| `TVBOX_TOKEN` 环境变量 | 已配置（≥16 字符） | **推荐**。独立的固定令牌，泄露时只需在 Cloudflare 后台更换这个变量，不影响任何人的登录状态 |
| 会话密钥派生 | 未配置 `TVBOX_TOKEN` | 64 位十六进制派生值；轮换 `SESSION_SECRET` / `AUTH_PASSWORD` 可使其失效，但会导致**全站重新登录** |

失败响应：

| 状态码 | 含义 |
|---|---|
| 401 | 令牌缺失或不正确 |
| 503 | 服务端没有任何密钥材料（`SESSION_SECRET` / `AUTH_PASSWORD` / `TVBOX_TOKEN` 均未配置） |

## 3. 导入客户端

### TVBox 及衍生版本

1. 打开 TVBox → 设置 → 配置地址；
2. 粘贴订阅链接 → 确定 → 等待拉取完成。

### OrionTV 等第三方客户端

在「订阅 / 接口配置」中填入同一链接。站点所有接口均开放 CORS（含 `OPTIONS` 预检），
无 Cookie 的客户端可以正常访问；海报图片走 `/api/image-proxy` 边缘代理，不受登录限制。

## 4. 订阅内容说明

| 字段 | 内容 |
|---|---|
| `sites` | 站内全部**启用中**的采集源。每源的 `type` 依据 api 后缀自动判定：`at/xml` 或 `.xml` 结尾按 XML 源（type 0），其余按 JSON 源（type 1） |
| `parses` | 仅 TVBox 内置的两种通用调度方式（Json 并发 / Json 轮询）。站内 `/api/parse` 依赖登录 Cookie，TVBox 无法使用，因此不下发 |
| `ads` | 常见广告域名过滤规则 |
| `wallpaper` | 站点截图（公开静态资源，无需登录） |
| `spider` | 空字符串（不使用自定义 spider） |

## 5. 缓存与更新

- 订阅响应头为 `Cache-Control: private, max-age=300`，客户端 5 分钟内可能命中本地缓存，
  强制刷新即可拿到最新版。
- 站内在 `/admin` 后台增删 / 修改源后，**无需改动订阅链接**——客户端重新拉取订阅即可同步。

## 6. 常见问题

| 现象 | 排查 |
|---|---|
| 返回 401 | 链接没有复制完整（丢掉 `token=` 段），或 `TVBOX_TOKEN` 被轮换、派生密钥被更新 |
| 返回 503 | 服务端未配置任何密钥材料，补齐 `SESSION_SECRET` 或配置 `TVBOX_TOKEN` |
| 返回 500「没有配置任何可用的视频源」 | 站内尚未导入采集源，先在 `/admin` 导入 |
| 有源但搜不到内容 | 采集源自身失效属常态，在 `/admin` 后台删旧换新 |
| 海报显示占位图 | 上游图床拒绝服务器出口时会回退占位图（而不是裂图），属于上游限制 |
| 播放失败 | 多数为采集源失效或该源不含此片，客户端内换源重试 |

---

_订阅格式基于 TVBox 标准 JSON 配置规范，兼容 TVBox 及其大部分衍生应用。_
